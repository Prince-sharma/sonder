Bench Plum · Prototype
Version index

Three cuts of the same prototype

Bench is a UI/UX prototype for an internal agent platform — a subject-matter expert builds an agent once, the team installs it. Each version below is a self-contained page; the version switcher in each page's top bar jumps between them without losing your place.

v1 · Pilot

The destination

A sales team eight weeks in: 8 live agents, adoption and impact data, approvals flowing, requests shipping. All three personas on full seed data.

  • Member, team admin and super admin, 23 routes
  • Design-notes overlay explaining every decision
  • Developer handoff section (object model, flows)
Open v1 → v2 · Simpler member UI

Members see less jargon

Same platform; the member-facing screens drop platform vocabulary and speak in outcomes. Admin screens keep the full detail they need.

  • No Verified badge, no version numbers for members
  • Suggest / Draft / Schedule / Event chips replaced with plain sentences
  • Store cards lead with what it does and when it runs
Open v2 → v3 · Fresh install

Day zero, and the road to v1

What the org sees when Bench is installed empty, with setup nudges at super-admin level first, then team-admin level. A journey control walks the org from empty to the full pilot.

  • Empty states everywhere, each with the next step
  • Super-admin setup checklist: team, people, connections
  • Team-admin path: context → build → test → publish
